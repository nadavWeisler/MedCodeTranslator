## Long Description (App Store + Play Store)

Med Code Translator is a fast, offline medical code reference for healthcare professionals, students, and researchers.

**Supported code systems:**
- ICD-9 and ICD-10 (diagnosis codes)
- ICD-11 (64-code curated subset, not full ICD-11)
- ATC Level 5 (drug classification)
- LOINC (600-code common-panel subset, not full LOINC)
- HCPCS Level II (supplies and non-physician services)
- CVX (vaccine codes)

**Features:**
- 🔍 Instant full-text search with fuzzy matching and autocomplete
- 🌐 English and Hebrew (עברית) language support
- 📴 Fully offline — no internet connection required
- 📱 Works on phone and tablet
- 🔒 No account, no login, no data collection

**Who is it for?**
Physicians, nurses, pharmacists, medical coders, students, and health IT professionals who need quick code lookups in the clinic, classroom, or field.
