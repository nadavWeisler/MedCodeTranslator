# SAFE_SCOPE

## Allowed Features (Current Safe Scope)
- Terminology/code lookup by code or text.
- Autocomplete and fuzzy matching that return existing terminology entries only.
- Dataset/source attribution and freshness metadata display.
- Bilingual UI/translation support.

## Prohibited Features (Out of Scope)
- Dosage recommendations.
- Drug interaction checking.
- Contraindication analysis.
- Treatment recommendation logic.
- Prescribing support workflows.
- AI-generated clinical guidance.
- Diagnosis assistance.
- Patient-specific risk scoring.

## Regulatory Escalation Risks
Adding patient-specific advice, treatment logic, or recommendations can elevate the product toward regulated medical device software obligations.

## Escalation Rule
If a proposed feature could influence diagnosis/treatment/prescribing decisions, pause implementation and complete legal/regulatory review before development.
