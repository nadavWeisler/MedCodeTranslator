# App Store Description (Compliance Draft)

MedCodeTranslator is a medication terminology and code lookup utility for research and administrative workflows.

It supports fast search, autocomplete, and fuzzy matching across multiple coding schemes.

Medical disclaimer: MedCodeTranslator is an informational reference tool only and is not intended for diagnosis, treatment decisions, prescribing, or medical advice. Always verify information with official clinical systems and licensed medical databases.

Privacy/safety: Do not enter patient-identifiable information or protected health information (PHI) into the app.
